To make a rootfs image for QEMU/KVM, you can choose between two primary methods: creating a lightweight Debian/Ubuntu image using debootstrap (best for development and debugging), or building an embedded rootfs using Buildroot (best for micro-VMs and testing).Here are the step-by-step instructions for both methods on an x86_64 Ubuntu/Debian host.Method 1: Using debootstrap (Full Debian/Ubuntu Environment)This method creates a native, fully functioning Linux environment inside an ext4 disk image file.Step 1: Install DependenciesInstall the necessary utilities on your host system:bashsudo apt update
sudo apt install qemu-utils debootstrap
Use code with caution.Step 2: Create a Blank Disk ImageAllocate a virtual disk file. For a minimal Debian environment, 2 GB to 4 GB is usually sufficient:bashqemu-img create -f raw rootfs.img 2G
Use code with caution.Step 3: Format the ImageFormat the raw image with an ext4 filesystem:bashmkfs.ext4 rootfs.img
Use code with caution.Step 4: Mount and Bootstrap the OSCreate a temporary mount point, mount your image, and use debootstrap to pull down a base Debian system:bashmkdir -p /tmp/rootfs
sudo mount -o loop rootfs.img /tmp/rootfs
sudo debootstrap --arch amd64 stable /tmp/rootfs http://debian.org
Use code with caution.(Replace stable with a specific version like bookworm or jammy if you prefer Ubuntu.)Step 5: Configure the Root Password and ConsoleChroot into your new environment to set a basic root password and prepare it for a headless serial console terminal:bashsudo chroot /tmp/rootfs /bin/bash -c "echo 'root:password' | chpasswd"
Use code with caution.Step 6: Unmount the ImageSafely unmount the image to flush changes to disk:bashsudo umount /tmp/rootfs
Use code with caution.Step 7: Boot with QEMU/KVMLaunch your new rootfs alongside your host's compiled or stock Linux kernel:bashqemu-system-x86_64 \
  -enable-kvm \
  -m 2G \
  -kernel /boot/vmlinuz-$(uname -r) \
  -drive file=rootfs.img,format=raw,if=virtio \
  -append "root=/dev/vda rw console=ttyS0" \
  -nographic
Use code with caution.Method 2: Using Buildroot (Ultra-Lightweight/Embedded)If you want an extremely small footprint or need to cross-compile for an architecture like ARM, use Buildroot.Step 1: Clone and Configure Buildrootbashgit clone https://github.com
cd buildroot
make qemu_x86_64_defconfig
Use code with caution.Step 2: Customize Output FormatsOpen the visual menu configuration tool:bashmake menuconfig
Use code with caution.Navigate to Filesystem images.Ensure ext2/3/4 root filesystem is checked.Select ext4 variant from the drop-down menu.Save and exit.Step 3: Compile the SystemRun the build tool (this may take 15–30 minutes depending on your CPU power):bashmake -j$(nproc)
Use code with caution.Step 4: Locate the Output and BootOnce finished, look inside the build outputs directory:bashcd output/images/
Use code with caution.You will find both a bzImage (the kernel) and a rootfs.ext4. Run it using the following shortcut:bashqemu-system-x86_64 \
  -enable-kvm \
  -M pc \
  -kernel bzImage \
  -drive file=rootfs.ext4,if=virtio,format=raw \
  -append "root=/dev/vda rw console=ttyS0" \
  -nographic
Use code with caution.If you want to customize your setup further, let me know:Which host architecture are you targeted for (e.g., x86_64, ARM64, RISC-V)?Do you need networking, SSH access, or GUI support configured inside the rootfs image?
